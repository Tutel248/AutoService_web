# ADR 0001: Вибір архітектурного стилю

**Статус:** Прийнято
**Дата:** 2026-09-26

**Контекст:** Проєкт СТО розробляється одним розробником. Розбиття на мікросервіси на старті створить надмірне інфраструктурне навантаження.
**Рішення:** Обрано архітектуру "Модульний моноліт" (Modular Monolith). Усі піддомени (Каталог, Бронювання, Гараж) живуть в одній кодовій базі та використовують спільну базу SQLite.
**Наслідки:** 
- Швидкий старт та легке тестування.
- Простий деплой одного процесу.
- Ризик "спагеті-коду", якщо не слідкувати за модульністю.
**Умови перегляду:** Якщо проєкт зросте до кількох команд розробників або якщо модуль Бронювання почне вимагати масштабування окремо від Каталогу.
