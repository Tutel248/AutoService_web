# ADR 0002: Шарова структура застосунку

**Статус:** Прийнято
**Дата:** 2026-09-26

**Контекст:** Для уникнення змішування HTTP-маршрутизації, бізнес-логіки та роботи з БД необхідний чіткий поділ на шари.
**Рішення:** 
- `api/` — містить налаштування ендпоінтів. Приймає запити, викликає сервіси, віддає DTO.
- `service/` — містить Use-Cases. Виконує валідацію та мапінг.
- `domain/` — містить чисті сутності та інваріанти.
**Залежності:** Зверху вниз (`api` -> `service` -> `domain`). 
**Заборони:** Шар `api/` не має права напряму звертатися до бази даних (DbContext).
