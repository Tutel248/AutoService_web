# Система бронювання послуг СТО

## Короткий опис
Проєкт являє собою веб-додаток для автоматизації процесу запису на діагностику та ремонт автомобілів. Система дозволяє відмовитися від ручного ведення записів, пропонуючи зручний інтерфейс для перегляду послуг та бронювання часу.

У майбутньому планується розширення функціоналу для ведення історії ремонтів конкретних автомобілів та автоматичного нагадування про необхідність планового технічного обслуговування.

## Хто користувачі (ролі)
1. Клієнт — переглядає список послуг, обирає потрібну та бронює час візиту.
2. Адміністратор / Механік — керує прайс-листом, переглядає розклад бронювань та змінює їх статуси.

## Основні сценарії використання
1. Перегляд послуг: клієнт відкриває головну сторінку і бачить актуальний прайс-лист.
2. Бронювання часу: клієнт обирає послугу, вказує контактні дані та обирає вільний слот.
3. Управління записами: адміністратор заходить у систему, бачить нове бронювання і підтверджує його.

## Функціональні вимоги
* Система повинна зберігати список доступних послуг у базі даних.
* Система повинна надавати клієнту можливість відправити запит на бронювання.
* Система повинна дозволяти адміністратору додавати та видаляти послуги з бази.

## Нефункціональні вимоги
* Відповідь сервера на завантаження списку послуг не повинна перевищувати 2 секунди.
* Клієнтська частина має коректно відображатися на мобільних пристроях.
* Дані повинні зберігатися локально за допомогою SQLite.

## Обмеження
* Система на даному етапі не буде обробляти онлайн-платежі.
* Система не буде інтегруватися з фізичними діагностичними сканерами по OBD-2 для автоматичного зчитування помилок у базу.
