# Глосарій термінів (Ubiquitous Language)

* **ServiceItem (Послуга):** вид робіт, доступний для замовлення.
* **Appointment (Запис):** зафіксований намір клієнта приїхати на СТО у визначений час.
* **Client (Клієнт):** фізична особа, яка замовляє послугу.
* **Vehicle (Автомобіль):** транспортний засіб клієнта, який потребує діагностики чи ремонту.
* **Mechanic (Механік):** співробітник СТО, який безпосередньо виконує роботу.
