# Аналіз домену AutoService

1. **Піддомен "Каталог послуг" (Catalog)**
   - `ServiceItem`: послуга, що надається (назва, ціна).
2. **Піддомен "Бронювання" (Booking)**
   - `Appointment`: запис клієнта на конкретний час.
   - `Client`: контактні дані замовника.
3. **Піддомен "Гараж" (Garage)**
   - `Vehicle`: автомобіль, що обслуговується.
