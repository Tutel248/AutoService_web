# Roadmap проєкту AutoService_web

## Найближчі 3-4 тижні розробки

* **Тиждень 3 — обробка бронювань (новий endpoint)**
  * Створення таблиці `Appointments` (Бронювання) в базі даних.
  * Додавання POST-ендпоінту `/appointments` для збереження запису від клієнта.
  * Оновлення HTML-клієнта: додавання форми для введення імені та часу.

* **Тиждень 4 — базова авторизація та ролі**
  * Впровадження перевірки доступу.
  * Створення прихованої сторінки адміністратора.
  * Розділення логіки: клієнти можуть лише переглядати послуги, адміністратор може їх редагувати.

* **Тиждень 5 — CRUD для послуг (управління прайсом)**
  * Додавання ендпоінтів POST, PUT, DELETE для таблиці `Items`.
  * Реалізація інтерфейсу адміністратора для додавання нових послуг та зміни цін без втручання в код.
